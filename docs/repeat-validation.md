## 实际视觉检查

查看了桌面首屏、头像签名、项目悬停、纸色到深绿的章节边界、能力区、经历与联系区，以及反向入场中间帧。头像文字不再依附两侧花章，签名独立居中，姓名与职业保留各自区域；中等宽度底部改为紧凑居中布局。流光仅显示在 2px 边缘，正文和肖像内没有扫光。

桌面 28px / 700ms、手机 12px / 400ms 的入场节奏保留。边界缓冲按不含动画位移的布局坐标计算；只有完全离屏后才重置，避免边缘反复闪动。鼠标点击焦点不阻止下一轮重播，键盘焦点目标立即显示。

当前正文配色未修改；2026-09-13 的正文对比度抽样结论保留在 motion-validation.md，本轮未重复全页面像素对比测量。新签名颜色 #405535 对纸色背景符合正文可读性要求；装饰流光不承载信息。
